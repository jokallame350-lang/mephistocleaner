# 🔒 Privacy Policy

**MephistoCleaner** is built upon a strict privacy-first foundation. We believe that an optimization and debloating tool must respect your digital privacy completely.

---

### 1. Zero Telemetry & Zero Tracking
* **No Analytics:** MephistoCleaner does not contain tracking pixels, analytics SDKs, session loggers, or telemetry agents.
* **No Cloud Connections:** The software does not transmit your personal data, hardware identifiers, network details, or optimization choices to any remote server.
* **100% Offline Capability:** The application functions fully offline without requiring an active internet connection (except when explicitly using the optional Winget app installer features).

### 2. Local-Only Execution
All registry modifications, cache purges, service state changes, and hardware diagnostics execute entirely within your local Windows environment and stay strictly on your machine.

### 3. Open-Source Transparency
The entire source code of MephistoCleaner is open-source and publicly auditable. You can inspect every line of PowerShell and XAML code directly in the repository to verify that no hidden network payloads or unauthorized background services exist.
