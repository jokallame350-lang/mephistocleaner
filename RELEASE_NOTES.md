# ⚡ MephistoCleaner v7.0.0 — The Human, Safe & Transparent Windows Tweaker

Hey everyone! 👋 I built **MephistoCleaner v7.0** to be the cleanest, safest, and most transparent Windows 10 & 11 optimization tool for gamers and developers.

### 🚀 What's New in v7.0

* 📊 **Live Hardware Dashboard:** Keep an eye on your CPU load & MHz, RAM usage (% and GB), and C: drive free space in real time without lagging your PC.
* 🔍 **Instant Search & Filter:** Just start typing (`DNS`, `RAM`, `CS2`, `Oyun`, `Defender`, `Telemetry`, etc.) to instantly find the tweak you're looking for.
* 🎯 **1-Click Presets:**
  * 🎮 **Esports Gamer Preset:** Unparks CPU cores, locks `MaxFrameLatency=1`, sets game priority to 38, and enables HAGS.
  * 🛡️ **Privacy & Debloat Preset:** Disables Copilot AI, DiagTrack telemetry, Bing web search in Start menu, and lockscreen promotions.
  * 🧹 **Deep Clean Preset:** Clears bloated shader caches (NVIDIA/AMD/DirectX), wipes temp folders, and sends a hardware TRIM pass to your SSD.
  * 💾 **Export / Import Profiles:** Save your favorite tweak configuration to a `.json` file and load it on any other PC.
* 📦 **Software Hub (Tab 8):** Select the apps you need (Steam, Discord, OBS Studio, Visual C++ All-in-One, 7-Zip, Brave, Chrome) and install them all silently via official Microsoft Winget packages.
* 🚀 **Standalone Native `.EXE`:** Instant 0.1-second startup with zero console window flash.
* 🎨 **Official Setup Wizard:** A lightweight 2 MB installer that creates clean Start Menu & Desktop shortcuts and a proper uninstaller.
* 🌐 **20 Languages & 10 Themes:** Native translations across 20 languages and 10 modern themes.
* 🛡️ **100% Safe & Reversible:** Create a restore point with one click (#149), or revert all core tweaks back to factory defaults (#150) anytime.
