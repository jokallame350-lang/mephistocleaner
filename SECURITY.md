| Version | Supported          | Status |
| :--- | :--- | :--- |

---

### Reporting a Vulnerability

The MephistoCleaner team takes the security and safety of Windows environments very seriously.

If you identify a security issue, vulnerability, or potentially unsafe registry modification in the codebase:

1. **Do NOT disclose it publicly** in public issues or discussions.
2. Please report the issue privately by emailing **jokallame06@hotmail.com** or by creating a [Private Security Advisory](https://github.com/jokallame350-lang/mephistocleaner/security/advisories/new) on GitHub.
3. Include detailed steps to reproduce the vulnerability, affected Windows builds (e.g., Windows 11 23H2 / 24H2), and potential risks.
4. We aim to acknowledge receipt of vulnerability reports within **48 hours** and release fixes promptly.
